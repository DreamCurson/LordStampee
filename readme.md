## Étape 2 : Maquette d'un timbre en focus

Explication des balises utilisées :

La section principale section class="presentation-timbre" sert à regrouper tous les éléments liés à un timbre précis. Elle contient à la fois les images et les informations descriptives, car ces deux parties font partie d’un tout cohérent : la présentation complète du timbre.

À l’intérieur, une seconde section est utilisée pour regrouper les différents articles, comme la description générale ou d'autres informations complémentaires. Cela permet de bien séparer la partie « visuelle » (les images) de la partie « texte » (les articles). Utiliser une section pour organiser les articles rend le code plus clair et permet d’ajouter facilement d’autres blocs d’information plus tard si nécessaire.

C’est un choix qui permet de structurer le contenu de manière logique, lisible et organisée :D !
